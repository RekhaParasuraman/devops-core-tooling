# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, respectful, and inclusive environment for everyone contributing to this project.

## Expected Behavior

All contributors are expected to:

- Treat others with respect and professionalism.
- Communicate politely and constructively.
- Accept feedback and different opinions.
- Focus on collaboration and problem-solving.
- Avoid harassment, discrimination, and offensive language.

## Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment or personal attacks.
- Discriminatory or offensive comments.
- Intimidation or disrespectful communication.
- Deliberately disrupting collaboration.

## Reporting Issues

If you experience or observe unacceptable behavior, report it to the project maintainers through the GitHub repository.

## Scope

This Code of Conduct applies to all project spaces, including GitHub issues, pull requests, discussions, and other project-related interactions.
